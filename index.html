Paste the whole reply, or just the JSON block. The payload comes back inside a fenced json code block, which is what gives your chat app a copy button — one tap on that and paste here. In-app AI

Off by default. Turn this on only if you have an Anthropic API plan and want the app to run the research itself. With it off, the app works entirely through Claude, ChatGPT, Gemini or Perplexity and the Run analysis in-app button is hidden.

Use my own API key to run analyses in-app

Your key is stored in this browser's local storage and sent directly to Anthropic — it never passes through any server of mine.

What this does. Instead of pasting 29,000 characters of protocol into Gemini, the app pastes three lines telling it to fetch protocol.md from your own site and follow it. Your method stays off the screen and out of the chat transcript.

What it does not do. The file still has to be publicly readable for the AI to fetch it, so anyone with the URL can open it, and the AI provider still processes its contents. This hides your prompt from over-the-shoulder view and from the chat history — it is not secrecy. For real confidentiality use RUN ANALYSIS IN APP, where the protocol goes straight to the API and is never pasted anywhere.

Requires the tool to have browsing on, and it will refuse if the URL is unreachable.
Cost warning. A full run makes 12–40 web searches and produces a very long report. Expect roughly ₹25–₹150 of API usage per analysis depending on model and depth. Set a spend limit in your Anthropic console.
Key safety. Anyone with access to this device or browser profile can read the stored key. Use a dedicated key with a low monthly cap, and revoke it if the device is lost. If you would rather not store a key at all, use "Copy prompt" and paste into a chat app instead.

Get a key at console.anthropic.com → API Keys. Model names above may need updating as new versions ship; edit the value in the dropdown if a call returns "model not found".

Data & privacy

Everything lives on this device: your key, saved analyses and worksheet scores. There is no backend and no analytics.

Removes the API key, every saved analysis and the reports built from it, the imported runs, the worksheet scores and all settings. Files you have already downloaded to your phone are yours and are not touched.
